# 绿行积分 · 视觉稿与切图标注

> 基准稿：`prototype-web/`（1440×900 桌面，内容区 1180px）
> 配套：`02-design-system.md`（组件规格）、`03-flows.md`（交互）
> 标注图：`docs/ui/redline/`（登录页、首页两张，含尺寸与间距）

## 1. 画布与栅格

| 项 | 值 |
| --- | --- |
| 设计画布 | 1440 × 900（浏览器视口），最小适配 1280 × 720 |
| 内容区宽度 | **1180px**，水平居中，左右安全边距 ≥ 24px |
| 栅格 | 12 栏，栏宽 76px，栏间距 **20px**（1180 = 12×76 + 11×20 + 2×24 ≈ 对齐） |
| 顶栏高度 | **64px**，白底，底部 1px `#E8EEF5` |
| 页面上下留白 | 上 26px，下 64px |
| 管理端侧栏 | 固定 **232px**（`#0B1220`），内容区左右 28px |
| 卡片间距 | 纵向 **16px**，双栏间距 **20px** |

| 资源 | 规格 | 格式 | 命名 |
| --- | --- | --- | --- |
| 品牌 Logo（图形） | 30×30（管理端 26×26），可缩放 | SVG | `logo-mark.svg` |

| 出行方式图标 | 24×24 线性 | SVG | `ic-mode-bus/metro/bike/walk.svg` |

**导出规则**：图标统一 24 视口、1.8 描边、`currentColor`；位图仅 @2x（`xxx@2x.png`），WebP 优先；单张 ≤ 100KB。

## 7. 交付与验收

1. 视觉稿：`prototype-web/`（可点击的静态原型）+ 12 张页面截图（`se-carbon-docs/shots-web/`）。
2. 标注：本文档 + 2 张标注图。
3. 切图：上线前按第 4 节清单导出，图标走 SVG sprite，礼品图走 CDN。
4. 验收口径：与 `03-flows.md` 第 9 节的交互清单逐条对照；像素偏差 ≤ 2px；颜色取 token，不写死色值。
