# 绿行积分 · 设计规范（Design System）

> 版本 v1.0　适用：用户端 + 管理端 Web　配套：`04-redline.md`（切图与标注）

## 1. 设计原则

1. **绿色是语义，不是装饰**：绿色只用于「正向、环保、成功、主行动」；避免整页铺绿。
2. **数字优先**：积分、减排量是产品主角，字号与对比度优先于插画。
3. **一屏一事**：每个页面只有一个主行动按钮（primary），其余为 secondary / ghost。
4. **可核对**：所有涉及加减分的界面必须能看到「余额」或「来源」，不让用户猜。

## 2. 色彩

### 2.1 品牌色

| Token | 值 | 用途 |
| --- | --- | --- |
| `--green-50` | `#ECFDF5` | 浅底、hover 背景、标签底 |
| `--green-100` | `#D1FAE5` | 选中态底色 |
| `--green-500` | `#10B981` | 图表主色、装饰 |
| `--green-600` | `#059669` | **主按钮、链接、强调数字** |
| `--green-700` | `#047857` | 主按钮 hover / 深色文字 |

### 2.2 中性色

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ink-900` | `#0F172A` | 标题、大数字 |
| `--ink-700` | `#334155` | 正文 |
| `--ink-500` | `#64748B` | 次要说明 |
| `--ink-400` | `#94A3B8` | 占位符、禁用文字 |
| `--line` | `#E8EEF5` | 分割线、输入框描边 |
| `--bg` | `#F5F7FA` | 页面底色 |
| `--surface` | `#FFFFFF` | 卡片、面板 |

### 2.3 语义色

| 语义 | 前景 | 背景 | 场景 |
| --- | --- | --- | --- |
| 成功/生效 | `#047857` | `#ECFDF5` | 已履约、生效中、已发放 |
| 警告/待办 | `#B45309` | `#FFFBEB` | 待处理、库存不足、规则变更须知 |
| 危险/失败 | `#BE123C` | `#FFF1F2` | 已取消、校验失败、删除 |
| 中性 | `#64748B` | `#F1F5F9` | 已归档、草稿、禁用 |

> 对比度：正文 `#334155` on `#FFF` = 9.3:1；`--ink-500` 仅用于 ≥12px 的辅助文字。

## 3. 字体与字号

字体栈：`-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`；
数字用等宽变体：`font-variant-numeric: tabular-nums`（表格与金额列必须开）。

| 层级 | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| Display | 34/40 | 700 | 余额、核心指标 |
| H1 | 24/32 | 700 | 页面标题 |
| H2 | 18/26 | 600 | 卡片标题 |
| Body-L | 15/24 | 400 | 表格正文 |
| Body | 14/22 | 400 | 常规正文 |
| Caption | 12/18 | 400 | 辅助说明、时间戳 |
| Micro | 11/16 | 500 | 角标、表头 |

## 4. 间距与栅格

- 间距基数 **4px**，常用档：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40`。
- 内容最大宽度 **1180px**，左右安全边距 24px（≥1440px 时自动居中）。
- 12 栏栅格，栏间距 24px；卡片内边距 20px（大卡）/ 16px（小卡）。
- 管理端：侧栏固定 **232px**，内容区左右 32px，卡片间距 16px。

## 5. 圆角 / 阴影 / 描边

| Token | 值 | 用途 |
| --- | --- | --- |
| `--r-sm` | 8px | 标签、输入框内元素 |
| `--r-md` | 10px | 按钮、输入框、下拉 |
| `--r-lg` | 14px | 卡片、面板 |
| `--r-xl` | 20px | 大容器、弹窗 |
| `--shadow-sm` | `0 1px 2px rgba(15,23,42,.06)` | 输入框、次级卡片 |
| `--shadow-md` | `0 1px 2px rgba(15,23,42,.04), 0 8px 24px rgba(15,23,42,.06)` | 卡片默认 |
| `--shadow-lg` | `0 16px 48px rgba(15,23,42,.16)` | 弹窗、下拉浮层 |
| 描边 | `1px solid var(--line)` | 卡片与输入框统一描边，避免纯阴影堆叠 |

## 6. 组件规格

### 6.1 按钮 AppButton

| 规格 | Primary | Secondary | Ghost | Danger |
| --- | --- | --- | --- | --- |
| 高度 | 40（大 44 / 小 32） | 同 | 同 | 同 |
| 内边距 | 0 20px | 0 18px | 0 14px | 0 18px |
| 圆角 | 10 | 10 | 10 | 10 |
| 背景 | `--green-600` | `#FFF` + 描边 | 透明 | `#BE123C` |
| 文字 | 白 14/600 | `--ink-700` 14/600 | `--green-700` 14/600 | 白 |
| hover | `--green-700` | `#F8FAFC` | `--green-50` | `#9F1239` |
| disabled | `#CBD5E1` 文字白，`cursor:not-allowed` | 描边变浅 | 文字 `--ink-400` | 同 |
| loading | 左侧 16px 旋转图标，宽度不变（预留空间防止跳动） | | | |

### 6.2 输入框 AppInput / 选择器 AppSelect

- 高 40，圆角 10，描边 1px `--line`，背景 `#FBFDFF`。
- focus：描边 `--green-500` + `box-shadow: 0 0 0 3px rgba(16,185,129,.14)`。
- error：描边 `#F43F5E` + 下方 12px 红色说明文字（错误文案写「怎么改」，不写「错误」）。
- 禁用：背景 `#F1F5F9`，文字 `--ink-400`。
- 前后缀图标 16px，与文字间距 8px。

### 6.3 表格 AppTable

- 表头：11px/600/`--ink-500`，行高 44，底边 1px。
- 行：高 52，hover `#FAFCFE`，分割线 `#F4F7FB`。
- 数字列右对齐 + tabular-nums；状态列固定宽度 96px。
- 空态：表格区显示 `AppEmpty`（插画 + 一句解释 + 主行动）。
- 加载：骨架屏 3 行，不用 spinner 占位。

### 6.4 标签 AppTag

高 22，圆角 6，字号 12/600，左右内边距 8；语义色见 2.3。

### 6.5 弹窗 AppModal / 抽屉 AppDrawer

- Modal：宽 480（确认）/ 640（表单），圆角 20，内边距 24，遮罩 `rgba(15,23,42,.45)`。
- 结构：标题 18/600 → 内容 → 底部右对齐按钮（次要在左，主行动在右）。
- 危险操作：主按钮用 Danger，且文案是动词（「取消订单」而非「确定」）。
- Drawer：宽 480，右侧滑入 240ms `cubic-bezier(.22,1,.36,1)`，用于行程详情、订单详情。

## 7. 状态设计（每个页面必须画全）

| 状态 | 要求 |
| --- | --- |
| 加载 | 首屏骨架屏；局部操作按钮 loading；列表追加时底部「加载中」 |
| 空 | 区分「无数据」与「筛选无结果」，后者提供「清除筛选」 |
| 错误 | 网络错误整页重试；业务错误就地提示且保留用户输入 |
| 无权限 | 403 页 + 「返回首页」 |
| 禁用 | 积分不足/库存不足时按钮禁用并说明原因（不弹窗） |

## 8. 可访问性基线

- 正文对比度 ≥ 4.5:1；大数字 ≥ 3:1。
- 所有交互元素可 Tab 聚焦，`:focus-visible` 显示 3px 绿色外圈。
- 图标按钮必须有 `aria-label`；表单 label 与 input 用 `for/id` 关联。
- 不用颜色单独表意：状态标签同时带文字。
- 动效尊重 `prefers-reduced-motion`。

## 9. 响应式断点

| 断点 | 宽度 | 行为 |
| --- | --- | --- |
| XS | < 640 | 单列，管理端侧栏折叠为抽屉 |
| SM | 640–1023 | 两列卡片，表格横向滚动 |
| MD | 1024–1279 | 用户端两列，管理端侧栏常驻 |
| LG | ≥ 1280 | 标准三列/双栏布局（设计基准） |
