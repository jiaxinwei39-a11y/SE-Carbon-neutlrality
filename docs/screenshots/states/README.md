## 状态是怎么造出来的

正常态与核算明细的两张是直接截图；其余「示意」态的做法是：复制页面到同目录的临时文件，在 `</body>` 前注入一段只在截图时生效的脚本，把 `<main>` 里的数据区替换成目标状态（保留页头，并去掉与空态矛盾的副标题），用 headless Chrome 截完即删临时文件。**仓库里不含任何注入代码**，产品页面保持原样。

生成脚本：`se-carbon-docs\gen-states.ps1`（工作区草稿，未入库）。

## 口径

- 「空」= 请求成功但没数据；「失败」= 请求没成功。两者的图标、主文案、是否带重试按钮都不同。
- 普通页面的失败态**不带 50001**；`50001` 只在对账页表示「对账服务不可用，不代表没有差异」。
- 「无权限」只出现在管理端页面（40301）；用户端他人的行程按 404 处理，与不存在同措辞。
- 截图基准 1440×900 / 1440×1000 / 1440×1150，与 `docs/ui/02-design-system.md` 的画布一致。
