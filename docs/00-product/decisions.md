## 模拟参数提案

以下全部用于课程演示，不是官方排放因子、不证明真实减排、不用于碳认证；待PM-01小组评审后才能作为运行环境种子规则。既有TC-01～TC-06夹具继续保持原值，不覆盖测试定义。

| 参数 | 建议值 | 单位与理由 |
| --- | --- | --- |
| 基准方式 | 私人燃油小汽车单人出行 | 沿用需求假设 |
| 基准因子 | 0.200000 | kgCO2e/km；沿用R-A测试夹具 |
| 公交因子 | 0.050000 | kgCO2e/km；沿用R-A测试夹具 |
| 地铁因子 | 0.030000 | kgCO2e/km；新增模拟值 |
| 骑行因子 | 0.000000 | kgCO2e/km；仅演示运行阶段简化，未计生命周期排放 |
| 步行因子 | 0.000000 | kgCO2e/km；同上，不宣称全生命周期零排放 |
| 积分系数 | 10.000000 | 分/kgCO2e；不与人民币兑换 |
| 商品示例 | 帆布袋20分，库存2 | 无真实价格和履约承诺，仅种子数据提案 |
| 规则版本 | DEMO-BUS-01、DEMO-SUBWAY-01、DEMO-BIKE-01、DEMO-WALK-01 | 每种方式独立版本与区间 |
| 规则生效起点 | 部署时显式配置 | 不预填追溯日期；补录测试用隔离测试库与受控时钟 |

计算：基准排放=距离×基准因子；实际排放=距离×方式因子；减排量=max(0,基准−实际)；积分=floor(减排量×系数)。10km公交为1.500000000kg、15分；地铁为1.700000000kg、17分；骑行和步行为2.000000000kg、20分。距离和因子精度、时间区间、幂等及事务规则仍以BR-01～BR-08为准。

原型的50分初始余额只是预设图示。真实演示必须通过有效业务流水累计到50分，例如10km公交15分、10km地铁17分、9km骑行18分；不能直接修改账户余额。兑换20分后30分，取消后恢复50分。
